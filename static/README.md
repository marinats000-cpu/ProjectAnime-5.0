# Anime Archive

Личный архив просмотренных аниме с виш-листом, заметками и рекомендациями.

## Что умеет

- Каталог из `data.json` с фильтрами по году, алфавиту и десятилетиям.
- Виш-лист (добавить / убрать, сортировка по дате добавления).
- Заметки к любому тайтлу (с подтверждением удаления).
- Добавление своих рекомендаций в каталог.
- 4 темы оформления (Ночь, Сакура, Океан, Лес) с фоновыми изображениями.
- Экспорт и импорт виш-листа и рекомендаций в `.txt` / `.json`.
- Страница прогресса со статистикой.

## Запуск

```bash
pip install -r requirements.txt
python app.py
